How the value is derived

Every protocol on this board has users, TVL and a product — but no token. To price the token it does not have, the radar looks sideways: inside the same snapshot, the protocols in each category whose tokens do trade vote with their real market-cap/TVL ratio, and the category's multiple is the median of those ratios. A pre-token protocol's implied value is its TVL times its category's multiple, adjusted by a momentum factor from its 7-day TVL change (damped, capped) and a maturity factor from how long it has been tracked (new protocols start at 0.80×, full weight at 900 days).

Read it honestly: an implied value is a claim about what a token could be worth if it traded like its category's median token. It is not a prediction that a token launches, that it launches soon, or that anyone is airdropped anything. It is a ranking device — a way to decide which of 342 tokenless protocols deserve a wallet's time first.
